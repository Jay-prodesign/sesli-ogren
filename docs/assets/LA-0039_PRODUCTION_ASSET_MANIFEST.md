# LA-0039 Production Asset Manifest

Status: ACTIVE / BOUNDED
Date: 2026-10-07
Scope: World-Class Experience / Golden Product Slice

## Rule

No decorative asset is admitted merely because the UI feels empty. Every signature asset must solve a visible experience role, retain provenance, preserve accessibility, and be validated in runtime.

## Current asset families

### ASSET-LA-0039-01 — D/Knot companion state family

- Experience role: functional guide and state acknowledgement at high-value moments.
- Surfaces: runtime loading, Home identity header, active Recall, result, Listen.
- States currently used: idle, think, listen, speak, correct, success.
- Identity authority: D/Knot remains locked under D-070.
- Production status: EXISTING / PRODUCTION-INTEGRATED.
- Reuse rule: use only where D/Knot communicates state, feedback or continuity; never as wallpaper.
- Accessibility: surrounding text must carry all semantic meaning; companion pose/color cannot be the sole signal.
- Runtime QA: narrow phone, large text, Reduced Motion and high-contrast readability.
- Replacement rule: any regeneration requires a separate D/Knot identity decision; LA-0039 does not authorize redesign.

### ASSET-LA-0039-02 — Material identity tile

- Experience role: make the learner's current source/material visually persistent across Home, Library and Workspace.
- Current production method: code-rendered semantic tile using media icon + typographic material identity.
- Asset type: PRODUCT COMPONENT, not generated artwork.
- Status: PRODUCTION-INTEGRATED.
- Why no generated cover art yet: arbitrary illustrations would weaken source truth and create unnecessary asset burden.
- Future admission trigger: only if real runtime/user evidence shows source recognition is materially weak without richer covers.

### ASSET-LA-0039-03 — Learning-state iconography

- Experience role: distinguish unassessed, developing, retrieved-once, review-needed, listening and attention states.
- Current production method: Material icon primitives + semantic product tokens.
- Status: PRODUCTION-INTEGRATED.
- Truth rule: icons amplify canonical text states; they do not invent new state semantics.
- Accessibility: state label remains visible; color/icon is never the only discriminator.

### ASSET-LA-0039-04 — Signature illustration family

- Experience role: NONE PROVEN YET.
- Status: NOT ADMITTED.
- Decision: do not generate generic education illustrations, decorative blobs, fake book covers or stock-style hero art during the Golden Slice.
- Admission condition: a concrete acquisition/onboarding/comprehension problem must remain after layout, type, D/Knot and material identity are working.
