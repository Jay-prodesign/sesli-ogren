## 7. Correct use of “quest / mission / path / world”

These terms are allowed only when they map to actual data.

### Safe
- “Bugünkü adım” = actual current next action.
- “Kaldığın yer” = actual continuation/resume state.
- “Sıradaki görev” = actual explainable next action.
- “Çalışma yolu” = real set of available actions: Recall / Listen / Explain / Focus.
- visual path/thread = real transition from result to next action.
- challenge framing = presentation of a real Recall action.

### Unsafe unless separately implemented/admitted
- “12/28 konu” without real topic model;
- “3/5 görev” without real session plan;
- locked/unlocked curriculum nodes;
- fake mastery bars;
- world territories tied to invented competency state;
- daily streak/XP;
- adaptive map nodes that imply learner modeling beyond current evidence.

Must not show:

- invented topic counts.

### Workspace
May show:
- material/source identity;
- actual LearnerState label;
- actual next action;
- Recall / Listen / Explain / Focus;
- real source quick-view;
- D/Knot only when state/feedback role exists.

May visually frame these as:
- current mission;
- study tools;
- learning path/thread;
provided no new semantic state is invented.

### Recall
May show:
- real prompt;
- real assistance state;
- answer field;
- Hint / Show Answer / Unknown;
- D/Knot LISTEN / THINK.

Must not show:
- fabricated question 3/5 unless a real session contract exists.

### Result
May show:
- actual outcome;
- actual assistance/evidence meaning;
- correct expression;
- source excerpt;
- actual next-action reason;
- D/Knot CORRECT / SUCCESS;
- visual continuation thread.

Must not show:
- mastery percentage;
- XP;
- unsupported “topic complete.”
