# LA-0040 Golden Slice Treatment Specs

Status: ACTIVE PROTOTYPE BRIEF
Purpose: create comparable visual treatments against the same product truth and content. Do not change learning semantics between treatments.

## Shared truth / invariant content
All treatments use the same representative material:
- Biyoloji — Fotosentez Notları
- Current state: Henüz ölçülmedi
- Primary active action: Hatırla
- Secondary modes: Açıkla, Odaklan, Dinle
- Recall success: İpucusuz hatırladın
- Truth boundary: one independent recall is not mastery
- Next action remains explainable and source-grounded

The visual tournament must not win by changing copy promises, adding fake scores, streaks, XP, fictional progress or extra product capability.

## Treatment A — Calm Premium Scholar (control)

### Product feeling
Quiet, editorial, serious, long-session comfortable.

### Composition
Home:
- very light warm canvas;
- material identity as editorial header, not giant colored slab;
- one restrained current-action card;
- secondary actions in compact rows;
- companion sparse/small.

Workspace:
- material header + source metadata;
- next active action prominent;
- study actions grouped by intent rather than equal cards;
- minimal decoration.

Recall payoff:
- result + source comparison + next action;
- almost no celebratory ornament;
- companion only as small supportive reaction.

### Color hypothesis
Warm neutral base + dark ink + one deep cobalt/ink-blue accent + subtle mint success.
No broad gradients.

### Strength to prove
Trust, focus, premium restraint.

### Failure risk
Too safe / too adult / low desire.

## Treatment B — Energetic Student Momentum

### Product feeling
Immediate, motivating, alive, young without becoming childish.

### Composition
Home:
- a visually active “today / continue” zone;
- compact material card with strong color identity;
- visible session momentum cues;
- action tiles with distinct semantic treatments;
- stronger companion presence.

Workspace:
- actions presented as visually distinct study tools;
- next action has a high-energy treatment;
- material-specific concept preview appears above the fold;
- stronger use of icons/shapes and state contrast.

Recall payoff:
- immediate success transition;
- answer/source comparison more visual;
- next action reads as continuation of a session, not a form submission;
- bounded micro-celebration.

### Color hypothesis
Neutral reading base + vivid cobalt/electric blue + aqua/mint + a warm coral/amber highlight.
Use bright color in bounded zones only.

### Strength to prove
Student desire and continuation.

### Failure risk
Noise, visual fatigue, gamification drift.

## Treatment C — Visual Learning Studio × Student Momentum (FOUNDER-SELECTED DIRECTION)

### Product feeling
A modern visual studio for learning from your own material: focused but alive, expressive but trustworthy.

### Core principle
**The material and learning state are the visual protagonists.**
Companion supports moments of guidance/payoff rather than owning the whole screen.

### Home
- warm/soft neutral canvas;
- material card behaves like a “living study object”, with source identity and one compact visual state;
- current next action integrated into material object rather than a separate generic hero;
- one visible “learning path” cue using real states only;
- secondary study modes use differentiated visual previews, not repeated cards;
- D/Knot appears as a small guide/reaction element, not app-icon decoration.

### Workspace
- becomes a learning dashboard/studio, not a menu;
- top area combines material identity + current state + next action;
- immediately below: a small visual source/concept strip derived from real material;
- study modes form a 2×2 or asymmetric tool cluster with unique visual roles;
- Recall is visually stronger than passive modes;
- Listen is calmer/ambient;
- Explain/Focus are interpretive/supportive;
- copy is shorter because structure shows meaning.

### Recall prompt
- content-first;
- question sits inside a strong material/source context;
- hint/reveal controls stay visually secondary;
- companion in attentive/listening state only if it helps.

### Recall payoff
- clear state transformation:
  answer -> source relationship -> evidence meaning -> next action;
- use compact visual comparison/highlight rather than paragraphs where safe;
- success surface may use a bounded accent burst/shape transition, never a fake score;
- next action continues the same visual thread;
- D/Knot reacts briefly and then yields visual priority to the learner’s result.

### Locked color direction
- Canvas / Cloud `#F7F8FC`;
- Ink / Midnight `#111827`;
- Pulse Blue `#3657FF` for primary/active learning;
- Deep Focus `#14224A` for immersive focus surfaces;
- Signal Aqua `#20BFA9` for listening/supportive positive states;
- Volt Lime `#C9F45D` only as a bounded signature momentum cue;
- no default purple/blue gradient brand treatment.

### Companion constraint
The previously generated round/plush humanoid mascot is rejected. If a companion is used, prototype a sparse 2D/vector-first living knot/signal guide: abstract/simplified, teen-credible, no animal/plush/baby-face/oversized-cartoon-eye identity, smaller routine footprint, meaningful states only.

### Signature visual primitives
1. Material Object — reusable material identity surface.
2. Learning State Ribbon — truthful state/next-action cue.
3. Action Tool Tile — differentiated by learning role.
4. Evidence Compare — answer/source relationship.
5. Continuation Thread — visually links result to next action.
6. Companion Moment — sparse stateful reaction.

### Motion
- subtle scale/position/color response;
- result transition 180–320ms where motion allowed;
- no looping decorative animation;
- Reduced Motion retains all information.

### Strength to prove
Highest combined identity + student desire + show-don't-tell + long-session comfort.

### Failure risk
Overdesign / too many visual primitives. Must stay disciplined.
