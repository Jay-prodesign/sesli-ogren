## Governing rule
The approved design plan is authoritative. Production difficulty is not design input. D/Knot and E/Tilt may not be redesigned to suit an image generator, rig tool, or runtime.

## Animation-first F0
F0 is **Canonical Form + Motion Anatomy**, not a static-art gate. Form and motion are explored together. Each candidate must establish canonical form, silhouette/minimal-size survival, body-integrated attention/expression, restrained idle life, listening/thinking/speaking deformation and early rig/deformation feasibility before F1.

## Mandatory generate → jury → repair loop
For each candidate and stage:
1. Lock the canonical target and parity contract.
2. Compile the internal generation prompt from the locked spec.
3. Generate **one candidate only**.
4. Jury the result against the immutable contract.
5. Any hard fail means **REJECT**.
6. Jury outputs failure codes plus concrete visible reasons; it does not invent a replacement design.
7. Compile a corrective prompt from those failure codes and explicitly preserve traits that already pass.
8. Regenerate and re-jury.
9. Repeat until PASS. If the same failure class persists and the surface appears incapable, change production surface/workflow rather than weakening the character brief.

## Failure taxonomy
The executable spec owns the canonical failure codes. Required classes include robot/face drift, abstract-logo/object drift, generic mascot drift, identity drift, weak attention system, static-only anatomy, state incoherence, silhouette collapse, effect dependence and prohibited archetype.

The two already rejected GPT attempts are negative evidence only:
- Attempt 1: **ROBOT_FACE_DRIFT / PROHIBITED_ARCHETYPE** — robot/AI assistant with conventional face/eyes.
- Attempt 2: **ABSTRACT_LOGO_OBJECT_DRIFT / WEAK_ATTENTION_SYSTEM** — attractive interlaced object but insufficient living-character/attention grammar.
Neither is a finalist or positive reference.

## D/Knot
Living, calm, intelligent interlaced character. Two broad continuous ribbons, deliberate over-under logic, negative space, asymmetry and structural tension carry identity. Attention uses body-integrated apertures/tension points, never conventional eyes. It must not become a decorative knot/logo.

## E/Tilt
Upright directional living character. Whole-body tilt plus integrated facet/notch carries orientation. No floating marker, robot/device, humanoid teacher or generic upright blob.

## Stage progression
F0 Form + Motion Anatomy → F1 Six-State Parity → F2 Three-Domain Strip → F3 Motion Proof → F4 Long-Session/Fallback. F3 validates/refines motion language established from F0; it is not the first motion consideration.

## Technology boundary
Frame-by-frame/GIF/video is not the default runtime model. Rig/deformation, reusable keyframed motion, blending and bounded micro-motion are the current production class. Rive, Spine or another runtime remains OPEN until the approved character/motion language can be preserved.

## Completion boundary
This task does not select D or E, merge PR #7, admit M5, deploy/release, or authorize paid-provider spend.
