# LA-0002 — Repository hygiene baseline

- **Status:** AWAITING_BRAIN_REVIEW
- **Handoff:** CLAUDE_HANDOFF_000
- **Executor:** Claude (Primary Engineer)

## Goal
Establish baseline repository hygiene so that secrets and local noise are not
committed and text files are consistent across operating systems.

## Scope
- **In:** `.gitignore`, `.editorconfig`, `.gitattributes`, `README.md`.
- **Out:** LICENSE (protected action); toolchain-specific ignore rules for
  toolchains that do not exist yet.

## Steps
1. Add `.gitignore` covering secrets (`.env*`, keys, credential JSON), private
   Drive exports, agent-local state, OS/editor noise, generic build artefacts.
2. Add `.editorconfig` (UTF-8, LF, final newline, 2-space default).
3. Add `.gitattributes` normalizing text to LF.
4. Add `README.md`: product name, bootstrap status, truth split, repo map,
   validation command, licensing-not-granted note.

## Acceptance criteria
- All four files exist and are readable UTF-8 text.
- README states that no application code exists yet.

## Verification
`python3 scripts/validate_bootstrap.py` (required-files and readable-text checks).

## Rollback
Revert the commit that introduced the files.
