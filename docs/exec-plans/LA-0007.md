# LA-0007 — Draft PR delivery and state/evidence reconciliation

- **Status:** IN_PROGRESS
- **Handoff:** CLAUDE_HANDOFF_000
- **Executor:** Claude (Primary Engineer)

## Goal
Deliver the bootstrap as an unmerged draft PR and leave the control files
consistent and ready for Brain review.

## Scope
- **In:** pushing `chore/repository-bootstrap`; opening a draft PR against `main`;
  updating `EXECUTION_STATE.json`, `ENGINEER_RETURN.md`, `TASKS.md`,
  `CURRENT_HANDOFF.md`.
- **Out:** merging, closing, marking ready, releasing, deploying; starting
  CLAUDE_HANDOFF_001.

## Steps
1. Run local validation; push branch.
2. `gh pr create --draft --base main --head chore/repository-bootstrap`.
3. Record PR number/URL and the head SHA in `EXECUTION_STATE.json`; set status
   `AWAITING_BRAIN_REVIEW`; complete `ENGINEER_RETURN.md`.
4. Reconcile statuses across `TASKS.md`, `CURRENT_HANDOFF.md`, state, and return.
5. Validate, commit, push the reconciliation; confirm CI; review final diff for
   scope leakage and secrets.

## Acceptance criteria
- Draft PR open and unmerged against `main`.
- State = `AWAITING_BRAIN_REVIEW`; repo, branch, base SHA, head SHA, PR recorded.
- All four control files agree.

## Verification
`gh pr view <n> --json isDraft,state,baseRefName,headRefName,headRefOid`;
`python3 scripts/validate_bootstrap.py`; CI checks on the PR.

## Rollback
Close the draft PR without merging (Product Owner / Brain decision) and delete
the branch; `main` is untouched throughout.
