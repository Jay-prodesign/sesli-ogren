# Execution Plans

One file per executable task: `LA-####.md`. A task in `TASKS.md` is only
executable when its plan exists here and its status is `READY` or `IN_PROGRESS`.

Each plan is short and executable and contains:

- **Task / Status / Handoff**
- **Goal** — one or two sentences.
- **Scope** — in / out.
- **Steps** — ordered, concrete.
- **Acceptance criteria** — checkable statements.
- **Verification** — commands or observations that prove the criteria.
- **Rollback** — how to undo safely.

Plans never contain private Drive content, secrets, or speculative product design.
