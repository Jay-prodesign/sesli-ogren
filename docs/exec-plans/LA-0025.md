## Need
The full-product continuity shell currently gives source-grounded orientation, Recall and Listen, but it does not yet turn a learner's material into a genuinely explanatory teaching experience. This is the next highest-value gap between the Golden-derived product and the first commercial product.

## Decision
Promote the already-proven Learning App `summary.v1` structured-generation seam rather than inventing a second AI stack. Keep generation server-side and source-version-bound. Generated interpretation must be visibly distinct from user-provided source content. Passive explanation/listening creates no mastery evidence.

No live provider, credential, paid API, or spend is authorized by this task. Until a real provider is separately authorized/configured, production must fail closed rather than show deterministic fake output as AI.

## First production slice
1. Production-owned grounded-generation contract derived from the proven LA-0012 seam.
2. A server boundary that accepts only authenticated/authorized source-version context and returns typed generated interpretation with provenance.
3. Material Workspace action **Açıkla** integrated into the existing learning loop, not a new top-level mode/tab.
4. Loading/error/unavailable states that remain useful and truthful.
5. Generated interpretation labels its source binding and never mutates Recall learner state.
6. After explanation, the dominant active continuation is Recall.

## Out of scope
Provider/vendor selection, paid API activation, generic AI gateway/framework, multi-provider routing, streaming/tools/multimodal, flashcard/quiz product tabs, automatic mastery/readiness inference from generated content, and broad engine extraction.

## Acceptance
- Explanation request is bound to the current source version; stale/wrong-source output is rejected.
- Source text and generated interpretation are distinguishable in UI/data contracts.
- Provider secrets cannot enter the Flutter client.
- Missing provider/config fails closed with a truthful unavailable state.
- Viewing/listening to explanation writes no mastery evidence.
- Recall remains the evidence-producing active step.
- Contract/server/UI tests cover success, stale-source rejection and unavailable/failure behavior.
- Bounded format/analyze/test checkpoint passes before completion.
