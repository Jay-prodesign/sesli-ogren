# LA-0027 — Multi-material Library + selected-material continuity

- **Status:** IN_PROGRESS
- **Handoff:** Post-LA-0026 commercial product continuity
- **Executor:** ChatGPT (bounded reversible engineering)
- **Owner / verifier:** Brain
- **Authority:** D-054, D-066, D-073, D-074 and post-M5 premise audit

## Objective
Remove the Golden-era single `m5-primary-material` product constraint so a learner can own multiple real materials, see them in Library, open the intended material, and keep Recall/Listen/Explain continuity bound to that selected material.

## Authoritative source references
- D-054 Home/Continue + Library + Material shared surfaces.
- D-066 app-first/concrete-first execution.
- D-073 evidence-backed continuity.
- D-074 bounded tranche governance.
- Post-M5 commercial-product premise audit.

## In scope
Learner-scoped active-material listing; stable material identity for newly added sources; Library rendering of multiple materials; explicit selected `MaterialId` through Material Workspace, Recall, Listen and Explain; Home continuation over a real selected/recent material; ownership/source/evidence isolation preserved.

## Out of scope
Folders/tags/search, cloud sync redesign, sharing, collaborative libraries, generic repository abstraction, Focus mode, monetization, provider activation, decorative library polish.

## Dependencies
- LA-0026

## Acceptance criteria
- Two independently ingested materials coexist for one learner.
- Library lists both active materials and opens the one tapped.
- Recall/Listen/Explain use the selected material, never a global fixture id.
- Evidence/state for material A cannot appear as material B continuation.
- Existing one-material users remain readable.
- Deleted/inactive material is not surfaced.
- One bounded tranche checkpoint passes before DONE.

## Required tests / evidence
Store tests for learner-scoped active listing and ordering; Flutter navigation/continuity test with two materials; one bounded format/analyze/test checkpoint at tranche end.

## Rollback / migration notes
Prefer additive API/navigation changes over schema migration. Preserve existing material/source/evidence records and the M5 fixture only as a test/backward-compatible fixture.

## Escalation conditions
Escalate before changing source ownership, evidence semantics, auth boundaries, or introducing cross-device/cloud synchronization behavior.

## Expected return
A first-commercial-product Library rather than a single-document Golden harness, with every learning action attached to the material the learner actually selected.
