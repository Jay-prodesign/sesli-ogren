## Steps
1. Extend checks listed in scope.
2. Add negative-test suite that mutates a temporary copy of the tree and asserts the expected failure message.
3. Workflow: `pull_request` and `push` to `main`; `permissions: contents: read`; checkout (`persist-credentials: false`) → validator → negative tests.

## Acceptance criteria
- Validator exits 0 on this branch and non-zero with a clear message on each violation class.
- Negative suite passes (each mutation is detected).
- Validation workflow uses read-only permissions and no secrets.

## Required tests / evidence
- `python3 scripts/validate_bootstrap.py` → `OK`.
- `python3 scripts/test_validate_bootstrap.py` → all tests pass.
- CI job `Validate repository control plane` green on the PR head.

## Rollback / migration notes
Revert the commit(s) that changed the files; no external state is affected. No data migrations apply (no application or database exists).
