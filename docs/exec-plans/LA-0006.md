# LA-0006 — Bootstrap validation script and CI workflow

- **Status:** AWAITING_BRAIN_REVIEW
- **Handoff:** CLAUDE_HANDOFF_000
- **Executor:** Claude (Primary Engineer)

## Goal
Provide a lightweight, dependency-free check of repository control integrity,
run locally and in CI. There is no application code, so no application tests
are claimed.

## Scope
- **In:** `scripts/validate_bootstrap.py` (Python 3 standard library only),
  `scripts/README.md`, `.github/workflows/bootstrap-validation.yml`.
- **Out:** language toolchains, linters, package managers, workflows with write
  permissions or secrets, `@claude` GitHub Action/App.

## Steps
1. Script checks: required control files/dirs; readable UTF-8 text (no NUL, non-empty);
   `EXECUTION_STATE.json` parses with required keys and allowed status;
   forbidden secret-bearing filenames absent; obvious secret token patterns and
   local user paths absent; `CLAUDE.md` import and read order; `CURRENT_HANDOFF.md`
   staging statement; `TASKS.md` hierarchy, IDs, fields, statuses, and Milestone 0
   exec-plan pointer resolution.
2. Workflow: `pull_request` and `push` to `main`; `permissions: contents: read`;
   checkout + `python3 scripts/validate_bootstrap.py`.

## Acceptance criteria
- Script exits 0 on this branch and non-zero with a clear message on a violation.
- Workflow uses read-only permissions and no secrets.

## Verification
- `python3 scripts/validate_bootstrap.py` → `OK`.
- Negative check: temporarily create an untracked `.env` → script fails; remove it.
- CI job `bootstrap-validation` green on the draft PR.

## Rollback
Revert the commit that introduced the files; no external state is affected.
