# LA-0004 — Task map and execution plans

- **Status:** AWAITING_BRAIN_REVIEW
- **Handoff:** CLAUDE_HANDOFF_000
- **Executor:** Claude (Primary Engineer)

## Goal
Create the task map and one executable plan per active bootstrap task.

## Scope
- **In:** `TASKS.md`; `docs/exec-plans/README.md`; `docs/exec-plans/LA-0001.md` … `LA-0007.md`.
- **Out:** product tasks; speculative architecture; any task beyond LA-0007.

## Steps
1. Write `TASKS.md` using headings: `## Milestone`, `### Sprint`, `#### Section`,
   `##### LA-#### — title`, each task with Status / Depends on / Owner /
   Executor / Verification / Exec plan fields.
2. Define LA-0001 … LA-0007 under Milestone M0; record next unallocated ID.
3. Add future milestones only as `PLANNED / NOT_EXECUTABLE` skeletons with no tasks.
4. Write the plan files using the template in `docs/exec-plans/README.md`.

## Acceptance criteria
- Hierarchy is strictly Milestone → Sprint → Section → Task.
- IDs unique, `LA-####` format, all required fields present, statuses from the legend.
- Every M0 exec-plan pointer resolves to an existing file naming the same task ID.
- Future milestones contain no tasks.

## Verification
`python3 scripts/validate_bootstrap.py` (TASKS structure and plan-pointer checks).

## Rollback
Revert the commit that introduced the files.
