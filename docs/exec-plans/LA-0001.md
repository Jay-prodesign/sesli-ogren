# LA-0001 — Pre-flight verification and canonical repository identity

- **Status:** AWAITING_BRAIN_REVIEW
- **Handoff:** CLAUDE_HANDOFF_000
- **Executor:** Claude (Primary Engineer)

## Goal
Prove the engineer is operating on the canonical repository in a clean state
before any mutation, and record governance-read availability.

## Scope
- **In:** read-only checks of local git and GitHub repository metadata; Drive
  fresh-read attempt by document title.
- **Out:** any change to repository settings, visibility, name, or ownership;
  installing/configuring Drive MCP or other automation.

## Steps
1. `git remote -v` → must be `https://github.com/Jay-prodesign/sesli-ogren.git`.
2. `git status --porcelain=v1 -b` → clean, on `main`, tracking `origin/main`.
3. `git fetch origin && git rev-parse HEAD origin/main` → equal; record as base SHA.
4. `gh repo view Jay-prodesign/sesli-ogren --json nameWithOwner,visibility,defaultBranchRef`
   → `PUBLIC`, default `main`.
5. `gh pr list --state all` and `git ls-remote --heads origin` → no conflicting branch/PR.
6. Attempt Drive fresh-read of the governance set by title; record outcome.

## Acceptance criteria
- Repo identity, visibility, default branch, clean state, and base SHA recorded.
- Drive read outcome recorded verbatim if unavailable.
