## What changed
The implementation keeps current product truth and canonical D/Knot while moving the Golden Slice toward the reconciled **Living Visual Learning Studio / Student Momentum** direction.

No new learner state, topic model, quiz counter, mastery percentage, generated source illustration or curriculum structure was added.

### Home
- material object is separated from the active next-action zone;
- actual learner state is shown as a truthful chip;
- current next action uses the shared Deep Focus + bounded momentum cue;
- Recall and Listen remain real available shortcuts;
- canonical D/Knot remains present as the Home companion.

### Material Workspace
- the previous four long repeated action cards were replaced with a compact differentiated 2×2 study-tool cluster;
- Recall / Listen / Explain / Focus have distinct semantic treatments;
- current next action is still dominant and backed by actual continuation state;
- canonical D/Knot is state-driven inside the next-action surface;
- source preview is explicitly labeled as real source text;
- technical “character count” metadata was replaced by a more learner-readable word count.

### Recall / payoff
- canonical D/Knot is integrated into a compact content-first header rather than dominating the screen;
- Recall challenge is framed visually without inventing a session counter;
- result -> source comparison -> next action is now a clear staged visual flow;
- source support and next-action reason remain fully grounded;
- no fake celebration score, XP or mastery claim was introduced.
